# Third-party software and data

This repository contains original application and research infrastructure alongside integrations with third-party software. Dependency manifests and upstream notices remain authoritative for those components. Inclusion here does not relicense upstream software or datasets.

Large datasets, model weights, generated results, and private account data are not distributed. Obtain external resources under their respective terms. This publication adds no license grant beyond existing component license declarations. Proprietary datasets are not licensed or distributed here.

## Provenance map

Python packages are listed in `requirements.txt` / `requirements-dev.txt`, and browser
build dependencies are pinned by `package-lock.json`; those packages retain their
own terms. Research word-breaking components include Rabbit-derived code under
`research/components/word_breaker/`; retained source headers are authoritative.
spaCy, Stanza, myPOS/myNER/myUDTree, Wiktionary/Kaikki and dictionary sources are
distinct external resources, not original model/data licenses granted by this repo.
The reader template references Met Museum imagery remotely; it is not redistributed
as a claimed original asset.
